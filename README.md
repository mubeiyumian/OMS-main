# 启动说明

## 本地需要支持的配置

JDK1.8 + Tomcat

> Spring 项目没有内置Tomcat服务器，需要自行配置

## 步骤

需要按SSM框架启动方式在IDE中进行配置，注意`Web.xml`是否选择正确

> 前端请求路径采用动态获取`contextPath`，因此访问前端页面需要加上`Tomcat`中设置的`Application Context`，如果设置为`/`直接访问端口号即可
>
> 
>
> 需要特别说明的是：由于项目二开新增了图片上传功能，因此如果需要对项目进行打包后在Tomcat根目录中进行部署启动，需要注意启动界面是否提示`upload`文件夹也一同部署成功，这里涉及到文件上传部分知识，可以自行查阅学习
